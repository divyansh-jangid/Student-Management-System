# Student-Management-System
A Student Management System built using Java and ArrayList with features to add, view, search, update, and delete student records. Developed to practice Core Java programming.


## Features
- Add a student
- View all students
- Search student by ID
- Update student details
- Delete a student

## Technologies Used
- Java
- ArrayList

## Current Storage
Student records are stored in memory using ArrayList.

## Future Improvements
- MySQL database integration using JDBC
- Input validation and exception handling

## How to Run
1. Clone or download this repository.
2. Open the project in VS Code or another Java IDE.
3. Compile and run the main Java class.
